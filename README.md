# MoCA Assist Professional HK

純前端 HK-MoCA 評估輔助網站，適合已獲合法授權的長者中心、社工、護士及認知障礙服務團隊內部使用。

## 新增功能
- 歷史紀錄加入「載入」及「刪除」鍵
- PDF / 列印報告改為專業報告格式
- 保留 Word 匯出
- 支援圖片題及時鐘手寫畫板

## 圖片資料夾
請把圖片放入：

```txt
images/
├── trail-making.png
├── cube.png
├── lion.png
├── rhino.png
└── camel.png
```

## 部署
GitHub Pages / Vercel 均可直接部署。建議 GitHub Repository 設定為 Private。
