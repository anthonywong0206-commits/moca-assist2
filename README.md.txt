# MoCA Assist Professional HK

純前端 HK-MoCA 評估輔助網站

- 長者中心
- 社工
- 護士
- 認知障礙服務團隊

作內部評估用途。

# 功能

## 1. 長者資料輸入

包括：

- 中文姓名
- 英文姓名
- 性別
- 年齡
- 教育年數
- 評估日期
- 評估員
- 中心 / 單位
